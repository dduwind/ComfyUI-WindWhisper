# WindWhisper 输出约定

> 本文件由 **WindWhisper** 添加，不是原 skill 的内容。
> 它只改**装法**，不改内容：本 skill 规定要输出的三段（英文提示词 / 中文提示词 /
> 负面提示词）一个字都不少，只是换成一种让 WindWhisper 认得出「提示词卡片」的写法。

## 为什么要换装法

WindWhisper 靠围栏的**语言名**认卡片 —— 只有写成 `prompt` 的那一块才会被识别成
「可以一键推到节点」的卡片。上面只规定了分几段、每段写什么，没规定语言名；
照原样输出的话，界面上的卡片和「复制 / 存库 / 推到节点」三个按钮**一个都不会出现**。

## 一次输出 = 下面这几个块

### 1. 英文提示词 → `prompt` 围栏

按上面规则推导出来的整段英文提示词，**整段**放进一个 `prompt` 围栏：

    ```prompt
    single character, full body, character concept art, ...
    ```

围栏起止**各自单独占一行**，收尾那行一次都不能漏 —— 漏了整段会被当成普通文字，
卡片和按钮都不会出现。围栏里只放英文提示词本身，不要写标题、不要写说明。

### 2. 中文提示词 → `text` 围栏

对应的中文翻译放进 `text` 围栏，**块内第一行写「中文对照」**，再接中文正文：

    ```text
    中文对照
    单个人物，全身，角色概念原画，...
    ```

**不要写成 `prompt`** —— 那一块是给画图节点用的，只能装英文。

### 3. 负面提示词 → `negative` 围栏

按上面规则该给的那段负面清单放进 `negative` 围栏：

    ```negative
    no multiple views, no turnaround, no character sheet, ...
    ```

负面词**不要**混进 `prompt` 块里；也**不要**在围栏外面写「负面提示词」这几个字，
直接开块就行。

### 4. 可调方向 → 全文最后一个 `text` 围栏

按上面规则列出的可替换关键词放进 `text` 围栏，**块内第一行写「可调方向」**：

    ```text
    可调方向
    正面站姿：`standing facing the camera, both hands on hips`
    动态跨步（当前）：`caught mid-step`
    侧后视角：`seen from behind at three-quarter angle, head turned back over the shoulder`
    ```

### 5. 围栏之外不写任何文字

不要开场白，不要"以下是为你生成的"，不要复述用户的需求。
**推导过程全部是内部动作** —— 挑母版、定重心与朝向、发散元素、扫自检清单，
这些一个字都不要输出，也不要写"已确认无遗漏"这类回执。

## 多版本怎么给

上面「用户信息不足时直接给 2-3 个方向、不要反问」照旧执行 ——
在 WindWhisper 里就是**输出多个版本**。注意三点：

- **每个版本一整组**，顺序必须是：`prompt`（英文）→ `text`（中文）→ `negative`（负面词）。
  这个顺序不能乱：负面词会被挂到**它前面最近的那张卡片**上，插错位置会配错版本。
- 中文块的第一行写成「版本一 · 中文对照」「版本二 · 中文对照」，
  多个版本才分得清谁对谁。
- 用户给的信息**足够**时只给一版，不要硬凑备选。

## 骨架样例（信息不足、给了两版时）

    ```prompt
    <版本一的英文提示词>
    ```
    ```text
    版本一 · 中文对照
    <版本一的中文翻译>
    ```
    ```negative
    <负面词清单>
    ```
    ```prompt
    <版本二的英文提示词>
    ```
    ```text
    版本二 · 中文对照
    <版本二的中文翻译>
    ```
    ```negative
    <负面词清单>
    ```
    ```text
    可调方向
    <按姿势构图维度列出的可替换关键词>
    ```
