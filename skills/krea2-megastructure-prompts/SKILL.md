# 巨构提示词生成器（Krea 2）

把一句模糊的"想要一个很震撼的巨大东西"翻译成 Krea 2 能读懂、**尺度真正读得出来**的英文长句提示词。

巨构的核心难题不是"大"，而是**让观者相信它大**。尺寸词（huge / giant / massive）对模型的边际效用极低；真正起作用的是**可测量的参照物、大气分层、结构可读性和镜头语言**。本 skill 的全部方法论围绕这四点展开。

---

## 工作流

### 1. 采集意图（缺什么就补什么，但别纠缠）

| 字段 | 说明 | 缺失时的默认 |
|---|---|---|
| 主体类型 | 建筑 / 生物 / 自然 / 机械 / 超现实混合 | 建筑巨构 |
| 结构语义 | 它凭什么立着：拱、桁架、悬挑、层叠、编织、生长、悬浮 | 按类型从剧本里选 |
| 尺度来源 | 参照物（人、城市、云、船、鸟群） | 人形剪影 + 云层 |
| 环境 | 荒漠 / 海面 / 雪原 / 云海 / 废墟城市 / 洞穴 / 太空 | 云海 + 逆光 |
| 情绪 | 敬畏 / 压迫 / 荒凉 / 神圣 / 恐怖 / 宁静 | 敬畏 + 荒凉 |
| 风格 | 写实概念美术 / 摄影 / 油画 / 3D / 水墨 / 废土蓝图 | 电影概念美术 |
| 画幅 | 9:16 / 2:3 / 16:9 / 2.35:1 / 1:1 | 垂直主体用 9:16，横向主体用 2.35:1 |
| 用途 | 概念设计 / 海报 / 壁纸 / 世界观设定 | 概念设计 |

**只问一次，最多两个问题；信息不足就按默认假设直接产出，并在回复里注明假设。**

### 2. 选场景剧本

读 `references/scene-playbooks.md`，按主体类型调对应的结构语法词库、材质词库与镜头建议。
剧本：**A 建筑巨构 · B 生物巨构 · C 自然/地质巨构 · D 机械载具巨构 · E 超现实混合巨构**。

### 3. 按七层组装（MEGA-STACK）

英文提示词的自然语序固定为下面七层，写的时候逐层填、不要跳层：

1. **CORE 主体与结构语法** — 它是什么，靠什么结构立起来，重复单元长什么样
2. **SCALE 尺度锚定** — 参照物 + 可测量数字 + 与画框的关系
3. **MATERIAL 材质与表面** — 主材、风化、附着物、湿滑/反光/积尘
4. **ENVIRONMENT 环境与占据** — 大气、天气、谁住在它上面、它被自然侵蚀成什么样
5. **LIGHT 光与大气** — 光源方向、时间、体积光、色温对比、大气透视分层
6. **CAMERA 镜头与构图** — 焦距、视角、构图、画幅
7. **STYLE 风格与渲染** — 媒介、笔触、调色、颗粒

七层的词库与句式在 `references/layer-vocabulary.md`。

### 4. 尺度自查（本 skill 的灵魂，必做）

逐条过一遍，任何一条不过就改提示词：

- [ ] 画面里有**至少一个可辨认的微小参照物**（人、船、鸟、车辆、城市街区）
- [ ] 或用**可测量数字**锚定（"a single window is the size of a city block"）
- [ ] 有**大气透视分层**：近景清晰 → 中景被雾/霭冲淡 → 顶部/远端消失
- [ ] **结构可读**：能看出重复的窗、接缝、肋、支柱、甲板，而不是一团糊的轮廓
- [ ] 有**镜头语言强化高度或跨度**（低角度仰视 / 极端远景 / 局部特写）
- [ ] 主体**占据画面 70–90%**，或明确"extend beyond the top of the frame"
- [ ] 尺寸形容词不超过 2 个（"colossal" "towering" 各用一次足够，其余靠参照物）

### 5. 输出

默认给 **1 条主提示词 + 2 条变体**（同一主体，三种风格/视角）+ 中文说明 + 参数建议。用下面的格式：

```
### 主提示词 · <风格名>

<英文长句，一段，3–6 句>

**中文要点**：<一句话说明这条词在强化什么>
**参数**：aspect_ratio <x> · creativity <raw|low|medium|high> · 模型 <Medium|Large>
```

如果用户只要一条，就只给主提示词，变体省略。

## Krea 2 硬规则（来自官方 prompting 指南，不可违反）

1. **自然语言长句**，不要逗号标签堆砌。Krea 2 是审美优先模型，长而具体的描写效果最好。
2. **不要元语言**：禁止 "the image shows…" "in this photo…" "a picture of…"。直接从主体开始。
3. **出字加引号**：需要在画面里渲染文字时，把文字放进双引号，如 `"TERMINUS VII"`。
4. **保真优先**：用户提到的主体、动作、颜色、空间关系全部保留；不要擅自加新角色/动物/道具。
5. **用户指定媒介必须遵守**：用户说 "photo of" 就写实摄影，说 "illustration of" 就插画，不要偷偷换媒介。
6. **尊重已有细节**：用户给的提示词已经很详细时，只做轻度润色定稿，不要大改重写。
7. **人物得体**：人物默认有衣物遮蔽，不做暴露或不当描绘。

## 参数速查

**creativity**（提示词越详细，creativity 应越低）

| 值 | 何时用 |
|---|---|
| `raw` | 本 skill 产出的完整长句提示词 → **默认推荐**，模型不额外发挥，严格照写 |
| `low` | 提示词写得很充分但希望补一点氛围 |
| `medium` | 提示词偏短（1–2 句），让模型补全风格与构图 |
| `high` | 探索阶段：只有一句话的种子，想看模型能开出什么方向 |

**aspect_ratio**

| 画幅 | 适合 |
|---|---|
| `9:16` / `2:3` | 垂直巨构：塔、巨兽站立、巨树、深井、垂直城市 |
| `16:9` | 通用；主体与环境并重 |
| `2.35:1` | 横向延展：城墙、舰体、山脉、天际线、地平线/轨道 |
| `1:1` | 对称纪念碑、正面立面、单体重心构图 |

**模型变体**

- **Krea 2 Medium** — 插画、绘画、动画、风格化表达更稳，更快更省。
- **Krea 2 Large** — 写实摄影、"raw" 质感、颗粒、运动模糊、低动态范围更强，出片上限更高。

**风格参考**：Krea 2 的风格迁移与 moodboard 很强。若用户想锁定某种画风，建议上传 1–10 张参考图并把文本提示词写简，比堆形容词有效得多——在输出里主动提示这一点。

## 常见翻车与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 看着"不大"，就是个大物件 | 只有尺寸形容词，没有参照物 | 加微小人形/船/鸟 + 可测量类比 |
| 巨物糊成一坨，看不出结构 | 缺结构可读性 | 加重复单元：窗格、肋、接缝、支柱、甲板、阶梯 |
| 画面平，没有纵深 | 缺大气透视 | 分三层写：前景锐利 → 中景雾化 → 远端消失于云/霭 |
| 主体太小，被风景淹没 | 没约束占画比例 | 写 "fills the frame" / "extends beyond the top edge" |
| 巨构像贴图，没有重量感 | 缺重力与承重表达 | 写支撑结构、悬挑、基座、垂坠的缆索/根须 |
| 光太平，没戏剧性 | 缺方向光与体积感 | 单一主光 + 逆光边缘 + 体积光柱 + 暗部压深 |
| 想要的风格出不来 | 形容词堆砌无效 | 改用媒介词（oil painting / matte painting / 3D render），或直接上风格参考图 |

## 快速用法

- 用户给一句话 → 走工作流 1→5，直接出主提示词 + 2 变体。
- 用户给一段自己的提示词 → 走"保真润色"模式：只补尺度锚定、光、镜头、媒介，**保留原句主体与措辞**，输出一版定稿 + 一版强化版。
- 用户要"探索方向" → 出 3–4 条差异明显的种子句（不同风格/不同视角/不同时间），建议 creativity `high`。
